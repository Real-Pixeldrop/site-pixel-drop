# Site Pixel Drop

Site vitrine [pixel-drop.com](https://pixel-drop.com). Statique, HTML pur, hébergé sur Hostinger.

## Structure

- `*.html` : les pages du site (URLs propres gérées côté serveur, `/integration-ia` sert `integration-ia.html`)
- `brand/` : logos et badges
- `docs/` : PDFs téléchargeables (plaquette, stack IA)
- `calculateur/` : calculateur d'automatisation (source : [calculateur-automatisation](https://github.com/Real-Pixeldrop/calculateur-automatisation))
- `67626d3c...` / `6772568b...` : assets (polices PP Mori et Gotham, images)
